# 🌲 NỀN TẢNG B2B XƯỞNG SẢN XUẤT PALLET GỖ (GEO SEO & CMS)

Dự án website chuyên nghiệp chuẩn B2B dành cho **Xưởng Sản Xuất Pallet Gỗ** với chiến lược tối ưu hóa Local GEO SEO cho các Khu Công Nghiệp (KCN) trọng điểm.

---

## 📂 Cấu Trúc Dự Án (Monorepo)

```text
PRJ_WOODPALLET_GEOSEO/
├── 📁 frontend/               # Giao diện Website B2B (HTML5, Tailwind CSS CDN, JS, SEO Schema)
│   ├── css/                  # Custom styling & pulsing animations
│   ├── js/                   # Giỏ báo giá LocalStorage, Modal, bộ lọc realtime
│   ├── index.html            # Trang chủ B2B
│   ├── san-pham.html         # Danh mục & bộ lọc sản phẩm
│   ├── chi-tiet-san-pham.html# Chi tiết pallet & bảng kỹ thuật
│   ├── bao-gia.html          # Bảng dự toán báo giá B2B & form KCN
│   ├── khu-vuc-geo.html      # Landing page Local GEO SEO (KCN VSIP 1)
│   ├── gioi-thieu.html       # Hồ sơ năng lực nhà máy 10.000m²
│   ├── lien-he.html          # Thông tin liên hệ & bản đồ KCN
│   └── server.js             # Local Dev Server thuần Node.js (Zero Dependency)
├── 📁 backend/                # Backend API & CMS Quản trị xưởng (Chuẩn bị phát triển)
│   └── README.md
├── package.json              # Quản lý script khởi chạy toàn dự án
├── .gitignore
└── README.md
```

---

## 🚀 Hướng Dẫn Khởi Chạy (Quick Start)

### Chạy Frontend từ thư mục gốc:
```bash
npm run dev
```
*(Hoặc gõ: `node frontend/server.js`)*

Mở trình duyệt truy cập: **`http://localhost:3000`**
