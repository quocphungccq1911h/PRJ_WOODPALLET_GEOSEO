# Backend & CMS Service (Pallet Gỗ Việt B2B)

Thư mục này dành cho hệ thống Backend API & CMS Quản trị nội dung:
- **Quản lý sản phẩm Pallet** (Thêm/Sửa quy cách, đơn giá sỉ, hình ảnh, chứng chỉ ISPM 15).
- **Tiếp nhận & Xử lý Yêu cầu Báo Giá B2B** (Bảng dự toán từ khách hàng KCN, xuất file PDF/Báo giá).
- **Quản lý bài viết SEO & Landing Page Local GEO** (Tạo động các trang KCN theo tỉnh thành).
- **Phân quyền người dùng** (Admin xưởng, Nhân viên kinh doanh, Quản lý kho).
